# Talent Nation — FDE Learning Journal

A living, version-controlled study notebook for Forward Deployed AI Engineering.

Start with [RESUME.md](RESUME.md) for the current checkpoint, [lesson index](lessons/README.md) for individual notes, and [GLOSSARY.md](GLOSSARY.md) for quick definitions and examples.

Each lesson includes a one-line takeaway, visual explanation, examples, engineering caveats, and practical applications. Notes are independently written summaries rather than verbatim copies of course materials. Coverage and demonstrated mastery are tracked separately.

After each study response, update the corresponding lesson, glossary (if needed), and resume checkpoint in GitHub. Keep historical notes and corrections. Do not commit credentials, personal records, or private datasets.
