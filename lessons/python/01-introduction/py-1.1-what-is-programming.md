# PY 1.1 — What is programming?

**Status:** Covered; latest lesson

**One-line takeaway:** Programming solves problems by expressing precise instructions a computer can execute on data.

## Study notes

```text
 DATA (ingredients) + PROGRAM (recipe)
                   -> COMPUTER (worker) -> RESULT (meal)
```

A computer receives information, executes instructions, processes data and produces output. Programming involves problem-solving (what must happen) and implementation (express it in code).

```python
prices = [1000, 500, 800]
total = sum(prices)
print(total)  # 2300
```

prices refers to a list, sum adds its values, total refers to the result, print displays it. This is an input-process-output pipeline. A programming language makes instructions easier for people to express; the runtime/compiler handles their execution or translation.

Python is useful for automation, data, scientific computing, ML, AI and web applications. Learning Python is not the same as learning AI. In an ultrasound application, image data is processed by software running a model on CPU/GPU; the result could be a muscle measurement. Training learns patterns from examples.

```text
Understand problem -> identify data -> design logic -> choose tools
 -> implement -> test/verify -> deploy -> measure impact
```
