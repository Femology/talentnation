# 3.1.2 — Filesystem navigation

**Status:** Covered

**One-line takeaway:** Understand file addresses and the working directory to navigate reliably.

## Study notes

```text
/
└── home/
    └── student/
        ├── documents/
        │   └── report.txt
        └── ai_projects/
            ├── train.py
            └── data/
                └── patients.csv
```

An absolute path starts at root, e.g. /home/student/ai_projects/train.py. A relative path depends on the current working directory, e.g. ai_projects/train.py from /home/student.

| Command or symbol | Meaning |
|---|---|
| pwd | Where am I? |
| ls | What is here? |
| cd | Change directory |
| . | Current directory |
| .. | Parent directory |
| ~ | Home directory (Bash expansion) |
| / | Filesystem root / path separator |

From /home/student/ai_projects, cat ../documents/report.txt displays the report. cd ../.. moves up two levels. cd ~ returns home. Linux filenames are generally case-sensitive; quote paths containing spaces. ./script.py attempts direct execution and generally needs executable permissions and an interpreter declaration; python3 script.py explicitly uses Python.

**FDE connection:** relative dataset paths can break if a training script is launched from a different working directory.
