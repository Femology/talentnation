# 3.1.3 — Python runtimes and PATH

**Status:** Covered

**One-line takeaway:** PATH tells the shell where to search for external programs; order can select a different Python installation.

## Study notes

```text
python3 -> /usr/local/bin/python3 (not found)
        -> /usr/bin/python3       (found, launch)
        -> /bin/python3           (not searched further)
```

Environment variables are named settings inherited by child processes, not necessarily global identical settings. PATH is a colon-separated directory list on Linux. Aliases, shell functions and built-ins can take precedence over external lookup.

```bash
echo "$PATH"
command -v python3
type -a python3
python3 --version
/usr/bin/python3 --version
```

The full path bypasses normal command-name lookup. which is common but type -a is more informative in Bash. A virtual environment isolates dependencies; activation normally prepends its bin directory to PATH.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip --version
```

Use the intended interpreter's pip module to avoid installing into the wrong environment. Some Ubuntu installs require the venv package first. Do not blindly overwrite PATH; export PATH="/opt/my_python/bin:$PATH" is an illustrative prepend, not required.

**Vocabulary:** executable, runtime, environment variable, PATH, version, virtual environment, dependency, package, pip.
