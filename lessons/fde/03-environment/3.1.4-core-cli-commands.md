# 3.1.4 — Core CLI commands

**Status:** Covered

**One-line takeaway:** Read commands as action, options and arguments; combine them carefully to create and navigate projects.

## Study notes

``text
ls       -la       /home/student
action   options   target
```

| Command | Purpose |
|---|---|
| pwd | Print current directory |
| ls | List entries |
| ls -la | Detailed listing including hidden entries |
| cd | Change directory |
| mkdir | Create directory |
| mkdir -p | Create missing parent directories |
| touch | Create empty file if absent, otherwise update timestamps |

```bash
mkdir -p hospital_ai/data
cd hospital_ai
touch train.py predict.py
ls -la
```

```text
hospital_ai/
├── data/
├── train.py
└── predict.py
```

mkdir creates a directory but doesn't enter it. touch doesn't add code or erase existing file contents. Hidden names begin with a dot, but hidden does not mean secure.

```bash
mkdir project; cd project; touch app.py
mkdir project2 && cd project2 && touch app.py
```

Semicolon continues regardless of prior success; && continues only on success. Prefer conditional chaining when commands depend on earlier steps.

**Vocabulary:** CLI, option, flag, argument, timestamp, scaffolding, command chaining.
