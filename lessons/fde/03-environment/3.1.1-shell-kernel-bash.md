# 3.1.1 — Shell, terminal, kernel and Bash

**Status:** Covered

**One-line takeaway:** The terminal is the interface, Bash interprets commands, and the kernel manages operating-system resources.

## Study notes

```text
You -> terminal -> Bash -> built-in or external program
                              -> OS/kernel services -> output
```

A terminal emulator provides a text interface. Bash is a shell and scripting language. The Linux kernel manages memory, processes, filesystems and devices. Bash can run built-ins without launching an external executable. Programs request kernel services through system calls.

```bash
echo "Hello from the shell"
pwd
ls
whoami
```

A typical prompt student@ubuntu:~$ shows user, host and home directory; do not type the prompt. The shell repeatedly reads, evaluates and displays output (REPL pattern). SSH enables secure remote access. Scripts can automate ordered tasks; handle failures instead of blindly continuing.

**Vocabulary:** kernel, shell, terminal emulator, Bash, CLI, command, argument, prompt, process, REPL, SSH, automation.
