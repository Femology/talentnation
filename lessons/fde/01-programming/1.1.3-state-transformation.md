## Study notes

State describes current values; a variable is a name referring to a value. A pipeline processes information through stages. Output and persistent state are not the same.

| Stage | Sender | Recipient | Status |
|---|---:|---:|---|
| Before | ₦10,000 | ₦2,000 | Pending |
| Validate | ₦10,000 | ₦2,000 | Validated |
| Transfer | ₦7,000 | ₦5,000 | Transferred |
| Verify | ₦7,000 | ₦5,000 | Confirmed |

For this simplified no-fee transfer, the total remains ₦12,000. That is an invariant. Debit and credit must be committed together in an appropriate ledger design.

```python
before = (10000, 2000)
after = (before[0] - 3000, before[1] + 3000)
assert sum(before) == sum(after)
```

State can live in memory, a browser, a database or an external service. A local variable update does not automatically update persistent records. Stale state is an outdated observation; observed state can differ from actual state.

```text
REQUESTED -> VALIDATING -> AWAITING CONFIRMATION -> BOOKING
                                                    | 
                              CONFIRMED <- verify <- UNKNOWN (timeout)
```

A state machine defines permitted states and transitions; also consider rejection, cancellation and expiry. A confirmed exclusive appointment must never have two owners.
