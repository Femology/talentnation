# 2.1.1 — High-level vs low-level languages

**Status:** Covered

**One-line takeaway:** High-level languages hide many machine details; lower-level tools offer more control with more responsibility.

## Study notes

Think of a steering wheel: it provides a simple interface to complex machinery. Machine code is native processor instructions; assembly uses mnemonics. C is higher-level than assembly but exposes more direct memory management than Python.

```python
patients = ["Amina", "Tunde"]
patients.append("Zara")
print(patients)
```

Python manages the underlying list storage. A name refers to an object. CPython relies heavily on reference counting and a cycle-detecting garbage collector. Memory can be reclaimed without immediately returning it to the operating system; other Python implementations differ.

Keeping unnecessary references can retain large objects and exhaust RAM. Automatic management does not make memory unlimited. Process large medical datasets in batches rather than needlessly loading all records.

**Vocabulary:** abstraction, machine code, assembly, allocation, reference, reference counting, garbage collection, memory leak, RAM.
