# 2.1.2 — CPython and bytecode

**Status:** Covered

**One-line takeaway:** CPython compiles readable Python into bytecode and executes it using its runtime.

## Study notes

```text
.py source -> compiler -> bytecode -> CPython execution engine -> CPU instructions -> result
```

```python
import dis
def calculate_balance():
    balance = 10000
    withdrawal = 3000
    return balance - withdrawal
print(calculate_balance())  # 7000
dis.dis(calculate_balance)
```

The dis module exposes bytecode; exact opcodes vary by version. Python is commonly called interpreted because bytecode normally executes through the runtime; some implementations or builds use additional optimizations. CPython is not Cython.

Imported modules may cache bytecode in __pycache__; directly running a main script normally does not create its own .pyc cache. Bytecode is not a standalone native executable and is not guaranteed compatible between versions. Source portability depends on dependencies and platform behavior.

**FDE connection:** Python orchestrates AI workflows while optimized native numerical libraries and GPUs can handle heavy calculations.

**Vocabulary:** source code, compiler, interpreter, bytecode, runtime, CPython, PVM, Cython, cache, native code.
