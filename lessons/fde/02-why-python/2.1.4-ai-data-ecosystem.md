## Study notes

A library is a collection of reusable tools; a framework provides a structure for building software. Python acts as a glue language coordinating other components.

```text
Raw data -> Pandas (clean tables) -> NumPy (numeric operations)
         -> scikit-learn / PyTorch (learn patterns)
         -> Matplotlib / Seaborn (visualize)
         -> API / application (deliver results)
```

```python
import numpy as np
prices = np.array([1000, 2000, 3000])
print(prices * 0.9)  # [900., 1800., 2700.]
```

Vectorization expresses operations across arrays without explicit element-by-element Python loops. Compiled routines often perform the work efficiently. NumPy handles numerical arrays; Pandas handles tabular data; scikit-learn provides classical ML; PyTorch and TensorFlow provide deep learning tools; CPU and GPU execute computation. CUDA supports computation on compatible NVIDIA GPUs.

ML learns patterns from examples; deep learning uses neural networks with multiple layers. Training adjusts parameters; inference uses a trained model. GPU usage is not automatic or appropriate for every operation. Python's ecosystem grew through accessibility, interoperability, community and investment; it is not the only AI language.

**FDE example:** prepare ultrasound data, train segmentation model, validate measurements and integrate inference into a safe application.
